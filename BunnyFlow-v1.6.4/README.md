# BunnyFlow 1.6.4

## Browser support

BunnyFlow runs only in desktop Microsoft Edge. Android and iOS Edge, Google
Chrome, Opera, Brave, Lemur, and other browsers are not supported.

## Use

1. Install the unpacked extension or its packaged ZIP.
2. Open BunnyFlow in the same browser and activate an eligible plan.
3. Open the extension and confirm that your BunnyFlow plan appears.
4. Select **Open Flow**.
5. Keep the blank page open while BunnyFlow prepares Flow.
6. When the project is ready, follow the on-screen reminder and choose the
   **Lower Priority** model from Flow's model dropdown.

The extension does not block or disable other installed extensions. Microsoft
Edge Add-ons remains available in desktop Microsoft Edge.
