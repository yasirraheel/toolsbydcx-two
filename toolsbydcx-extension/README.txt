ToolsByDcx Flow 1.0.1

1. Extract this ZIP to a folder.
2. In Microsoft Edge, open edge://extensions and enable Developer mode.
3. Select Load unpacked and choose this folder (the one containing manifest.json).
4. Open https://toolsbydcx.com/user/flow-extension and get a connection code,
   or ask your administrator/reseller for a code. Codes expire in 15 minutes.
5. Enter the six-digit code in the extension popup, then select Open Flow.
6. If Google asks for CAPTCHA or another manual verification, complete it and
   select Resume. Do not share connection codes with anyone else.

An active plan and an assigned Google Flow account are required.
Use a dedicated browser profile. The extension cannot prevent a person who
controls the browser from inspecting credentials or disabling the extension.
The extension is distributed for manual installation, not through an add-ons store.
